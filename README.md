# C Programs

Beginner-friendly programs written in C.

| Program | Description |
|---|---|
| `calculator.c` | Menu-driven calculator: add, subtract, multiply, divide, modulus, power |
| `student_grades.c` | Stores students' marks using structs, calculates average and grade, finds the topper |

## How to run

```bash
gcc calculator.c -o calculator -lm
./calculator

gcc student_grades.c -o student_grades
./student_grades
```
